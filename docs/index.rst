PhotoShare API
==============

PhotoShare is a REST API for managing users, photos, tags,
comments, ratings, and image transformations.

The application is built with FastAPI, SQLAlchemy, and PostgreSQL.
Cloudinary is used for image storage and transformations, while JWT
is used for authentication and authorization.
